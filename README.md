# 乐彩助手（微信小程序）

彩票**数据统计与娱乐选号**工具，支持双色球、大乐透两种玩法，内置 AI 数据助手。

> ⚠️ **重要声明**：彩票开奖是独立随机事件，任何历史数据都无法预测未来开奖结果。本工具提供的统计、选号与 AI 功能仅供娱乐参考，不构成任何投注建议。理性购彩，量力而行；未满 18 周岁禁止购买彩票。

## 功能

| Tab | 功能 |
| --- | --- |
| 开奖 | 双色球/大乐透最新开奖结果、近 8 期开奖列表 |
| 选号 | 单式/复式投注；均衡机选、热号倾向、冷号倾向三种模式；复式支持自定义各区号码个数并实时计算注数与金额 |
| AI | AI 对话助手：解读冷热号、遗漏值等概念，基于内置数据做描述性分析；流式回复、多轮上下文、可切换模型 |
| 走势 | 主区/副区热号冷号 Top10、遗漏榜、和值与奇偶比，支持近 30/50/100 期窗口切换 |
| 我 | 选号记录入口（本地存储，含复式标识）、数据说明、理性购彩声明 |

### 复式投注规则（以官方为准）

- **双色球**：红球 6-20 个、蓝球 1-16 个，主区/副区至少一侧超过单式（红 7+ 或蓝 2+）
- **大乐透**：前区 5-20 个、后区 2-12 个，至少一侧超过单式（前区 6+ 或后区 3+）
- 注数 = C(主区个数, 单式主区数) × C(副区个数, 单式副区数)；按基本投注 2 元/注计价，不含追加

## 数据来源

- 中国福利彩票官网（cwl.gov.cn）与中国体育彩票官网（sporttery.cn）官方接口
- 内置双色球、大乐透各 100 期真实开奖数据，统一格式 `[期号, 日期, 主区数组, 副区数组]`
- 数据为静态内置（更新至 2026-11-03），纯展示无需联网

## AI 助手（云服务）

- 基于 WorkBuddy 云服务的大模型调用（免密钥，publishableKey 鉴权），默认模型 `glm-5.3-flash`，可切换
- AI 页系统提示词注入近 5 期开奖、热冷号与遗漏数据；硬性约束：拒绝预测中奖号码、必须说明开奖随机性
- **流式降级**：优先走 SDK 分块流式（enableChunked），运行时不支持时自动降级为普通请求一次性拉取 SSE 并解析
- 每个调用点均以 system 消息开头（平台要求）

## 开发与构建

```bash
npm install          # 安装依赖（云服务 SDK + miniprogram-ci）
npm run build-npm    # 见下方说明，生成 miniprogram_npm
```

- **npm 构建**：原生小程序不能直接引用 `node_modules`，改动依赖后需重新构建：

  ```bash
  node -e "require('miniprogram-ci').packNpmManually({
    packageJsonPath: './package.json',
    miniprogramNpmDistDir: './',
  })"
  ```

  云 SDK 在 `dependencies`，构建工具在 `devDependencies`，不会互相污染。
- **预览**：微信开发者工具导入项目目录即可（测试号 `touristappid`）；或通过 WorkBuddy 应用卡预览
- **域名白名单**：开发阶段 `project.config.json` 已设 `urlCheck: false`；正式发布前需将云服务网关域名加入微信后台 request 合法域名

## 发布注意事项

1. 小程序内不得出现「预测中奖」「提高中奖概率」等宣传语——本项目已在文案与 AI 提示词中硬性规避
2. 需完成微信小程序类目审核（彩票类目限制严格，建议以「工具-信息查询」类目提交）
3. 隐私清单（`.wbapp_*.privacy.json`）为空数组：未调用任何隐私接口
